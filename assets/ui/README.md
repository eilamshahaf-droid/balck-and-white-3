# Interface textures

Stationery for the interface (the UI brief "the god's desk", 2026-11-18): masking tape,
index card, kraft tag, clothes peg, a sewing button (coins), push pin, brass fastener,
kraft card (tiles) and a pink carbon form. Made by Eilam with Google's image tools and cut
out by the UI thread (full-size originals in the project folder `ui/assets/`); scaled down
here for the game. Used through `data/ui_theme.tres` and `data/ui.tres`.
