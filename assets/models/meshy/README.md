# Meshy props

Generated for this game with Meshy (meshy.ai) through its API on a paid plan, which
gives the account owner full rights to the output. These are AI-generated assets:
list them when declaring AI content (for example on Steam).

Each model went through text to 3D (smart topology, triangle mesh, PBR texture,
remove lighting), then its textures were cut to 1K JPEG and the model scaled to its
real size in metres with its base at y = 0. The prompts, task ids and helper scripts
are in the project's shared folder (models/meshy-props, models/meshy-tests).

`trash_bag.glb` has two blend shapes made in Blender: `squash` (pressed from above)
and `dent_x` (pushed from one side).
