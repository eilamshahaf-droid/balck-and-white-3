# Researcher: חוקר מקומי

כלי קטן שרץ על המחשב שלך, בלי מנוי ובלי טוקנים. כותבים מילות חיפוש, רואים תמונות ממקורות חינמיים עם רישיון פתוח, מסמנים את הטובות, והוא שומר אותן בתיקייה (למשל תיקיית Claude בגוגל דרייב, שהאמן קורא ממנה). לכל תיקייה נוסף קובץ `CREDITS.txt` עם היוצר והרישיון של כל תמונה.

## הפעלה
1. ודא ש-Node מותקן (כבר יש לך).
2. לחיצה כפולה על `run_researcher.cmd`. הדפדפן נפתח ב-http://localhost:5177 (השרת פתוח רק למחשב שלך).
3. פעם אחת: פתח **Settings** והדבק את נתיב תיקיית הדרייב המסונכרנת, למשל `G:\My Drive\Claude`. מקש ימני על התיקייה ב-Explorer, "Copy as path", ומוחקים את הגרשיים.

## שימוש
כותבים חיפוש באנגלית (`brownstone facade New York`), בוחרים מקורות, Search. לוחצים על תמונות כדי לסמן. בשדה "Save into subfolder" כותבים שם תת-תיקייה (למשל `facades`), ו-Save selected.

## מקורות
- **Wikimedia Commons**: בלי מפתח בכלל. הכי טוב לתמונות של מבנים אמיתיים. הרישיון מופיע על כל תמונה (חלקם דורשים לתת קרדיט, וזה נשמר ב-CREDITS.txt).
- **Openverse**: בלי מפתח. מאגד תמונות פתוחות מ-Flickr ועוד, הרבה צילומי רחוב ובניינים אמיתיים. הרישיון מסומן על כל תמונה.
- **Pexels**: מפתח חינמי, דקה אחת: https://www.pexels.com/api/ (הרשמה, ו"Your API Key").
- **Unsplash**: מפתח חינמי: https://unsplash.com/developers (New Application, ומעתיקים את ה-Access Key).

## הערות
- המפתחים נשמרים רק אצלך, בקובץ `config.json` (לא עולה ל-git).
- אין תלויות: אין `npm install`.
- שימוש מסחרי: Wikimedia תלוי ברישיון של כל תמונה. לצורך רפרנס לאמן זה בסדר, אבל אל תכניס תמונה למשחק בלי לבדוק את הרישיון שלה.
